## 🎨 Design System

### Couleurs :
- **Fond principal** : #F9FAFB (gris très clair)
- **Bulles IA** : Dégradé violet-rose (#9333EA → #EC4899)
- **Bulles utilisateur** : #FFFFFF avec border violet
- **Texte IA** : #FFFFFF
- **Texte utilisateur** : #374151 (gris foncé)
- **Accents** : #9333EA (violet SACRA)

### Typographie :
- **Messages** : 16px, line-height 1.5
- **Timestamps** : 12px, gris clair
- **Titres** : 20px, bold

### Animations :
- Apparition des messages : Fade in + slide up (300ms)
- "En train d'écrire" : 3 points animés
- Scroll automatique : Smooth scroll vers le bas
